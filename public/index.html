    Tasks
    
        
      
    
      
    Multi-step work that any app can continue. Apps checkpoint after each step on the task's git branch; when one stops (for example at its usage limit), ask another to resume_task and it carries on from the last checkpoint. Tasks for repos the hub doesn't sync (company work) are private.

    Drop these into a repo so coding agents (Claude Code, Codex, Cursor, Gemini CLI, Antigravity, Copilot) know about the hub and your standing instructions. Nothing is written to GitHub from here.
